# 任务与调度系统

> 源码：`core/utils/task_manager.py` + `core/utils/background.py` + `core/utils/scheduler.py` + `core/utils/notification.py`

## 一、模块概览

| 模块 | 核心类 | 一句话 |
|------|--------|--------|
| `task_manager.py` | `TaskManager` | 持久化任务看板（CRUD + 依赖图 + 工作树绑定） |
| `background.py` | `BackgroundManager` | 后台线程执行命令 + 持久化记录 + 完成通知 |
| `scheduler.py` | `CronLock` + `CronScheduler` | Cron 定时调度（持久化 + 抖动 + 错过检测） |
| `notification.py` | `NotificationQueue` | 优先级通知队列（支持 key 折叠） |

## 二、TaskManager — 持久化任务看板

### 存储

每个任务一个文件：`ai_output/.tasks/task_{id}.json`

```json
{
    "id": 1,
    "subject": "实现用户认证",
    "description": "JWT + OAuth2",
    "status": "in_progress",
    "blockedBy": [],
    "blocks": [2],
    "owner": "alice",
    "worktree": "task-1-auth",
    "worktree_state": "active",
    "closeout": null,
    "created_at": 1716955200.0,
    "updated_at": 1716955300.0
}
```

### 状态流转

```
pending ──claim──→ in_progress ──done──→ completed
   │                    │
   └──── blocks ───→ blockedBy (双向依赖)
                        │
                    └──deleted──→ deleted
```

### API

```python
class TaskManager:
    def create(self, subject, description="") -> str:
        # 创建 task_{next_id}.json, 返回 JSON
    
    def get(self, task_id) -> str:

    def update(self, task_id, status=None, owner=None,
               add_blocked_by=None, add_blocks=None) -> str:
        # 更新字段
        # status="completed" 时自动从其他任务的 blockedBy 中移除
        # add_blocks 时自动双向更新 (被阻塞任务的 blockedBy 也添加)
    
    def bind_worktree(self, task_id, worktree, owner="") -> str:
        # 绑定工作树: worktree_state → "active"
        # 如果 status=pending → 自动改为 in_progress
    
    def unbind_worktree(self, task_id) -> str:

    def record_closeout(self, task_id, action, reason="", keep_binding=False) -> str:

        # keep_binding=False 时重置 worktree 路径
    
    def list_all(self) -> str:
        # 格式化列表:
        # [ ] #1: 实现用户认证 owner=alice
        # [>] #2: 编写测试 (blocked by: [1])
        # [x] #3: 搭建项目 owner=bob
```

### 依赖关系

```
task_1.blocks = [2]         ← 任务 1 阻塞任务 2
task_2.blockedBy = [1]      ← 任务 2 被任务 1 阻塞

当 task_1 status → "completed":
    _clear_dependency(1)
    → 从所有任务的 blockedBy 中移除 1
    → task_2.blockedBy = []  (任务 2 变为可认领)
```

## 三、BackgroundManager — 后台任务执行

### 架构

```
BackgroundManager
    ├── tasks = {}              # 内存中的任务状态
    ├── _notification_queue     # 完成通知队列
    └── dir = TOOL_RESULTS_DIR/background/
        ├── {id}.json           # 任务元数据
        └── {id}.log            # 命令输出
```

### 执行流程

```python
bg.run("npm test")
    │
    ├── 生成 task_id (uuid[:8])
    ├── 记录 tasks[task_id] = {status: "running", ...}
    ├── 持久化到 {id}.json
    ├── 启动 daemon 线程
    │   └── _execute(task_id, command)
    │       ├── subprocess.run(command, timeout=600)
    │       ├── 安全解码 (UTF-8/GBK)
    │       ├── 写入 {id}.log
    │       ├── 更新 tasks[task_id].status = "completed"
    │       ├── 持久化到 {id}.json
    │       └── 推送到 _notification_queue
    └── 立即返回 "后台任务 xxx started: npm test"
```

### API

```python
class BackgroundManager:
```

## 四、CronScheduler — 定时调度

### CronLock — PID 锁

防止多个会话同时触发同一个定时任务：

```python
class CronLock:
    def acquire(self) -> bool:
        # 检查锁文件中的 PID 是否仍在运行
        # 进程已终止 → 锁过期 → 可以接管
        # 进程仍在运行 → 锁有效 → 返回 False
    
    def release(self):
        # 如果锁属于当前进程 → 删除锁文件
```

锁文件格式：`ai_output/.cron_lock` 内容仅为 PID 数字。

### cron_matches — 表达式匹配

```python
def cron_matches(expr: str, dt: datetime) -> bool:
    """五字段 cron 表达式匹配"""
    # 支持: * */N N N-M N,M
    # 字段: 分钟 小时 日期 月份 星期
    # 注意: cron 星期 0=Sunday, Python 0=Monday, 已自动转换
```

示例：
| 表达式 | 含义 |
|--------|------|
| `*/5 * * * *` | 每 5 分钟 |
| `0 9 * * 1-5` | 工作日 9:00 |
| `30 14 1 * *` | 每月 1 日 14:30 |

### 后台检查循环

```
_check_loop (每秒):
    │
    ├── 同一分钟只检查一次 (防重复触发)
    │
    └── _check_tasks(now):
        │
        ├── 遍历所有任务:
        │   │
        │   ├── 自动过期: recurring 任务超过 7 天 → 移除
        │   │
        │   ├── 抖动偏移: 如果 cron 在 :00/:30 触发，
        │   │   应用 1-4 分钟偏移 (避免所有任务挤在同一秒)
        │   │
        │   └── cron_matches(task["cron"], check_time)?
        │       └── 是 → 推送到通知队列
        │           ├── recurring: 继续保留
        │           └── one-shot: 标记删除
        │
        └── 清理过期和单次任务 → 持久化
```

### 抖动设计 (Jitter)

```python
def _compute_jitter(self, cron_expr: str) -> int:
    # 如果分钟字段是 0 或 30
    # → 返回 hash(cron_expr) % 4 + 1  (1-4 分钟偏移)
    # 目的：避免所有 :00 任务在同一秒触发
```

### 错过检测

## 五、NotificationQueue — 优先级通知

### 特性

1. **四级优先级**：immediate(0) > high(1) > medium(2) > low(3)
2. **Key 折叠**：相同 key 的新消息替换旧消息

### API

```python
class NotificationQueue:
    def push(self, message, priority="medium", key=None):
        # 如果 key 不为 None 且已存在 → 替换旧消息
        # 按优先级排序
    
    def drain(self) -> list:
        # 返回所有消息 (按优先级排序) + 清空队列
    
    def peek(self) -> list:
        # 返回所有消息 + 不清空
```

### 折叠示例

```python
nq = NotificationQueue()
nq.push("任务 A: 50%", key="task_a")
nq.push("任务 A: 75%", key="task_a")   # 替换上一条
nq.push("任务 A: 100%", key="task_a")  # 再次替换

nq.drain()  # → ["任务 A: 100%"]  (只保留最新)
```

**用途**：后台任务频繁更新进度时，避免上下文被过时信息淹没。
