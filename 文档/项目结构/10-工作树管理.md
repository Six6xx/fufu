# 工作树管理

> 源码：`core/utils/worktree.py`

## 一、什么是 Git 工作树？

Git worktree 允许在同一个仓库中创建多个独立的工作目录，每个目录可以 checkout 不同的分支。适合多任务并行开发：

```
repo/                           ← 主工作目录 (main 分支)
├── ai_output/.worktrees/
│   ├── fix-bug/                ← 工作树 1 (wt/fix-bug 分支)
│   ├── add-feature/            ← 工作树 2 (wt/add-feature 分支)
│   └── index.json              ← 工作树索引
```

## 二、WorktreeManager

### 初始化

```python
class WorktreeManager:
    def __init__(self, repo_root, tasks=None, events=None):
        self.repo_root = repo_root
        self.tasks = tasks        # TaskManager (可选，用于绑定任务)
        self.events = events      # EventBUS (可选，用于事件日志)
        self.dir = repo_root / "ai_output" / ".worktrees"
        self.index_path = self.dir / "index.json"
        self.git_available = self._check_git()
```

### 核心操作

#### create — 创建工作树

```python

    # 1. 验证名称 (1-40 字符, 字母/数字/._-)
```

### 事件日志

所有操作都通过 EventBUS 记录：

```
worktree.create.before  → worktree.create.after (或 .failed)
worktree.enter
worktree.run.before     → worktree.run.after (或 .timeout)
worktree.remove.before  → worktree.remove.after (或 .failed)
worktree.keep
worktree.closeout.keep / worktree.closeout.remove
task.completed (关联任务完成时)
```

### 名称验证

```python
def _validate_name(self, name: str):
    if not re.fullmatch(r"[A-Za-z0-9._-]{1,40}", name or ""):
        raise ValueError("工作树名称无效")
```

只允许字母、数字、点、下划线、连字符，最长 40 字符。

### 与 TaskManager 的交互

```
create(name, task_id=1)
    │
    ├── git worktree add ...
    ├── index.json: {task_id: 1, ...}
    └── tasks.bind_worktree(1, "fix-bug")
        └── task_1.json: {worktree: "fix-bug", worktree_state: "active"}

remove(name, complete_task=True)
    │
    ├── git worktree remove ...
    ├── tasks.update(1, status="completed")
    ├── tasks.record_closeout(1, "removed", ...)
    └── index.json: {status: "removed", ...}
```
