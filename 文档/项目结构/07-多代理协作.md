# 多代理协作

> 源码：`core/teammate/functions.py` + `core/teammate/manager.py` + `core/protocol/store.py`

## 一、模块概览

```
teammate/
├── functions.py    ← 任务扫描与认领（无状态函数）
```

## 二、任务扫描与认领 (functions.py)

### 任务文件格式

每个任务是 `ai_output/.tasks/task_{id}.json`：

```json
{
    "id": 1,
    "subject": "修复登录 Bug",
    "description": "...",
    "status": "pending",
    "owner": "",
    "blockedBy": [],
    "blocks": [2],
    "required_role": "backend"
}
```

### 认领流程

```
scan_unclaimed_tasks("backend")
    │ 扫描 .tasks/ 目录
    │ 过滤: status=pending, no owner, no blockers, role match
    ▼
返回 [task_dict, ...]
    │
    ▼

    │

    ├── 重新读取 task JSON（防止并发修改）
```

## 三、TeammateManager (manager.py)

### 职责

管理多个协作 Agent（"队友"）的生命周期：
1. **注册表**：持久化队友信息到 `config.json`
2. **工作循环**：每个队友在独立线程中运行 agent loop
3. **消息驱动**：通过 MessageBUS 收发消息
4. **任务自动认领**：空闲时自动扫描并认领匹配任务

### config.json 格式

```json
{
    "team_name": "default",
    "members": [
        {"name": "alice", "role": "backend", "status": "working"},
        {"name": "bob", "role": "frontend", "status": "idle"}
    ]
}
```

### spawn() — 创建队友

```python

```

### 队友工作循环

每个队友线程运行一个**双阶段循环**：

```
┌──────────────────────────────────────────┐
│  阶段 1：主动工作 (最多 50 轮)             │
│  ┌──────────────────────────────────┐    │
│  │ 1. 检查收件箱                     │    │
│  │    ├── shutdown_request → 退出    │    │
│  │    └── 其他消息 → 加入对话历史     │    │
│  │                                   │    │
│  │ 2. 调用 LLM (带工具列表)           │    │
│  │                                   │    │
│  │ 3. 处理响应                        │    │
│  │    ├── 纯文本 → 打印，break        │    │
│  │    └── tool_calls → 执行，继续     │    │
│  │                                   │    │
│  │ 4. idle 工具 → 进入阶段 2          │    │
│  └──────────────────────────────────┘    │
│                                          │
│  阶段 2：空闲轮询 (最多 IDLE_TIMEOUT 秒)  │
│  ┌──────────────────────────────────┐    │
│  │ 每 POLL_INTERVAL 秒:              │    │
│  │ ├── 检查收件箱                     │    │
│  │ │   └── 有消息 → resume，回到阶段1 │    │
│  │ │                                  │    │
│  │ └── 扫描未认领任务                  │    │
│  │     └── 有匹配任务 → 认领，回到阶段1│    │
│  │                                    │    │
│  │ 超时 → status="shutdown", 退出     │    │
│  └──────────────────────────────────┘    │
│                                          │
│  resume=True → 回到阶段 1                 │
└──────────────────────────────────────────┘
```

### 队友可用工具

```
原生工具: bash, read_file, write_file, edit_file
+ send_message(to, content, msg_type)    ← 给队友发消息
+ read_inbox()                           ← 读取收件箱
+ shutdown_response(request_id, approve) ← 响应关机请求
+ plan_approval(plan)                    ← 提交计划审批
+ idle()                                 ← 进入空闲阶段
+ claim_task(task_id)                    ← 手动认领任务
+ MCP 工具 (如已连接)
```

### 身份上下文注入

长对话中模型可能"忘记"自己是谁，所以每次从空闲恢复时注入身份提醒：

```python
def _ensure_identity_context(messages, name, role, team_name):
    identity = f"[System Reminder] 你是 '{name}', role: {role}, team: {team_name}"
    messages.append({"role": "user", "content": identity})
```

## 四、RequestStore (protocol/store.py)

### 用途

持久化**协议请求**（关机审批、计划审批），支持跨代理的请求-响应模式。

### 请求格式

```
ai_output/.team/requests/
└── {request_id}.json
```

```json
{
    "request_id": "a1b2c3d4",
    "kind": "plan_approval",
    "from": "alice",
    "to": "lead",
    "status": "pending",
    "plan": "...",
    "created_at": 1716955200.0,
    "updated_at": 1716955200.0
}
```

### API

```python

    def create(self, record: dict):

    def update(self, request_id: str, **changes) -> bool:
        # 线程安全地更新请求字段 + updated_at 时间戳
        # 使用 threading.Lock
```

### 审批流程示例

```
alice 调用 plan_approval(plan="重构登录模块")
    │
    ▼
REQUEST_STORE.create({
    "request_id": "a1b2c3",
    "kind": "plan_approval",
    "from": "alice", "to": "lead",
    "status": "pending",
    "plan": "重构登录模块"
})
    │
    ▼
BUS.send("alice", "lead", plan_text, "plan_approval", ...)
    │
    ▼ (lead 处理)
    │
lead 批准 → shutdown_response(request_id, approve=True)
    │
    ▼
REQUEST_STORE.update("a1b2c3", status="approved", ...)
BUS.send("lead", "alice", "", "shutdown_response", ...)
```
