# 项目目录与类索引

> 以 2026-10-13 工作区源码为准。索引覆盖项目自有 Python 模块的顶层类，以及核心前端模块；不展开 `claude-code/` Python 运行时、`llm_harness/` 外部项目、模型权重、缓存和用户运行数据。`core/agent_team.py` 首行语法问题已修复；Python 源码语法扫描通过。实际服务启动仍需安装项目依赖。

## 一、从哪里进入

```text
__main__.py                     CLI 参数解析；选择 CLI 或 Web 模式
  ├─ core.agent.Agent            CLI 模式
  └─ core.server.create_app      FastAPI / WebSocket 模式
       ├─ CompanionAgent         即时反应、委派执行、结果总结
       ├─ AgentTeam              执行层封装 Agent
       └─ Agent                  推理、工具、会话等核心运行时
```

│   └── utils/                   记忆、技能、任务、调度、供应商等通用服务

## 三、关键运行链路

```text
浏览器 index.html
  └─ web_html/js/01-config.js … 19-lipsync.js
       └─ WebSocket /ws 与 core/server.py
            ├─ 接收 text/audio/toggle 等消息
            ├─ CompanionAgent：即时反应 → 执行委派 → 总结
            ├─ AgentTeam：封装执行及执行结果
            └─ Agent / AsyncInferenceEngine：LLM 流、工具调用、回调
                 ├─ 原生工具 / MCP / 权限审批
                 ├─ Session、Memory、Skill、Task 等服务
                 └─ 语音、认知、桌面等扩展能力
```

**讲解提示：**不要把图说成严格的类继承结构。当前代码主要是对象组合与委托：`CompanionAgent` 持有 Agent/AgentTeam，Agent 持有多个管理器；前端与后端通过 WebSocket 协议解耦。
