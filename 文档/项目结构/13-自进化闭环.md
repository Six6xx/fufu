# 自进化闭环

> 源码：`core/agent_team.py` + `core/utils/skill_registry.py` + `core/utils/dream.py` + `core/server.py` + `core/tools/native/graph_tools.py`

## 一、设计目标

让 AI 助手在持续使用中自我改进：
1. **从对话中学习** — 会话结束后自动提取知识、用户偏好、犯错模式
2. **从执行中进化** — 工具调用模式分析，自动创建可复用技能
3. **跨层链接** — 记忆（feedback/mistake/skill_learned）驱动技能修正和防御

## 二、完整数据流

```
用户对话（WebSocket）
    │
    ├── 执行过程中 ──────────────────────────────────────────┐
    │   AgentTeam.execute(user_input, tool_callback=orig_cb)  │
    │   ├── _pre_analysis(user_input) → 注入图谱提示          │  预分析
    │   └── wrapped_cb, log = _collect_execution_log(orig_cb) │  收集执行日志
    │       └── agent.agent_loop(..., tool_callback=wrapped_cb)
    │             └── 每次工具调用 → wrapped_cb 追加到 log
    │   └── agent_loop 返回后：
    │       ├── _self_check(log) → 检测模式
    │       │   ├── redundant: 连续 3+ 次相同工具
    │       │   ├── skill_candidate: 重复子序列（长度 3，出现 ≥ 2 次）
    │       │   └── retry: 相邻两次相同工具 + 相同参数
    │       ├── auto_create(user_input, log, result) [如果 >5 步 + skill_candidate]
    │       └── suggest_merge() → 检测可合并的技能对
    │
    └── 会话结束时（WebSocket finally）────────────────────────┐
        _session_messages = list(agent.history)                  │
        _session_id = agent.current_session_id                   │
        threading.Thread(daemon=True).start()                    │
            │                                                     │
            ▼                                                     │
        ┌──────────────────────────────────────────────────────────┤
        │ 后台线程: _session_end_digest()                           │
        │                                                          │
        │ Step A: 记忆消化（dream.consolidate_session）             │
        │   1. extract_fragments — 提取知识片段                     │
        │   2. classify — 分类（user/feedback/project/              │
        │                  mistake/skill_learned）                  │
        │   3. deduplicate — MinHash > 0.8 合并                    │
        │   4. link — keyword overlap 关联                         │
        │   5. decay — 60 天未访问记忆衰减                          │
        │                                                          │
        │ Step B: 技能进化（skill_registry.evolve_skills）          │
        │   场景 1: feedback 记忆 → 技能修正（追加约束）            │
        │   场景 2: mistake 记忆 → 防御性技能（create_guard_skill） │
        │   场景 3: skill_learned 记忆 → 新技能（auto_create）      │
        └──────────────────────────────────────────────────────────┘
```

## 三、模块职责

### 3.1 AgentTeam — 执行层（`core/agent_team.py`）

**预分析**（`_pre_analysis`）：在委托 `agent_loop()` 之前，快速判断任务类型并注入上下文提示：

```python
def _pre_analysis(self, user_input: str) -> str | None:
    """检测分析关键词，注入图谱提示。"""
    graph_exists = _find_graph_json() is not None
    analysis_keywords = ["分析", "结构", "架构", "依赖", "调用", "关系",
                         "影响", "谁调用了", "在哪里", "怎么工作的", ...]
    needs_analysis = any(kw in user_input for kw in analysis_keywords)
    if needs_analysis and graph_exists:
        return "[系统提示: 项目有知识图谱可用。建议先用 graph_query 了解相关结构...]"
    elif needs_analysis and not graph_exists:
        return "[系统提示: 项目尚未构建知识图谱。建议先 graph_update 构建...]"
    return None
```

在 `execute()` 中调用，提示文本追加到 `user_input` 前面，引导 Agent 使用图谱工具。

**执行日志收集**：通过包装 `tool_callback` 实现，不修改 `agent.py`。

```python
def _collect_execution_log(self, original_callback):
    log = []
    pending_calls = {}  # tool_name → args
    def wrapper(event_type, data):
        if event_type == "tool_call":
            pending_calls[data.get("name", "")] = data.get("args", {})
        elif event_type == "tool_result":
            log.append({
                "tool": data.get("name", ""),
                "args": pending_calls.pop(data.get("name", ""), {}),
                "result": str(data.get("result", ""))[:500],
            })
        if original_callback:
            original_callback(event_type, data)
    return wrapper, log
```

**自检分析**（`_self_check`）：

| 检测类型 | 条件 | 含义 |
|---------|------|------|
| `redundant` | 连续 3+ 次相同工具 | 可能冗余步骤 |
| `skill_candidate` | 长度 3 的工具序列出现 ≥ 2 次 | 可提取为技能 |
| `retry` | 相邻两次相同工具 + 相同参数 | 可能失败重试 |

**自动技能创建**：当 `tool_count > AUTO_SKILL_MIN_STEPS(5)` 且自检结果为 `skill_candidate` 时，调用 `skill_registry.auto_create()`。

**AgentTeamResult 扩展字段**：

```python
@dataclass
class AgentTeamResult:
    task_result: str
    success: bool = True
    tool_calls_made: int = 0
    error: str | None = None
    execution_log: list[dict] = field(default_factory=list)  # 结构化执行日志
    skill_created: str | None = None       # 自动创建的技能名
    merge_suggestion: dict | None = None   # 合并建议
```

### 3.2 SkillRegistry — 技能注册表（`core/utils/skill_registry.py`）

**权限模型**：

| 字段 | 值 | 含义 |
|------|---|------|
| `source` | `"manual"` | 用户手动创建 |
| `source` | `"auto"` | AI 自动创建 |
| `locked` | `false` | AI 可读写 |
| `locked` | `true` | AI 只读（用户锁定） |

**核心方法**：

| 方法 | 功能 |
|------|------|
| `auto_create(task, log, result)` | 从执行日志自动创建技能 |
| `suggest_merge(threshold=0.6)` | 检测可合并的相似技能对 |
| `merge_skills(a, b, body)` | 合并两个未锁定技能 |
| `create_guard_skill(topic, content)` | 创建防御性技能（避免重复犯错） |
| `record_usage(name)` | 记录技能使用次数 |
| `evolve_skills_from_memories(mm)` | 从记忆驱动技能进化（3 种场景） |

**evolve_skills_from_memories 三种场景**：

```
场景 1: feedback 记忆 + 已有技能
  → 提取关键词 → find_by_keyword → 追加约束到技能正文
  → 结果: corrected 列表

场景 2: mistake 记忆
  → has_guard(topic) → 不存在则 create_guard_skill()
  → 结果: guarded 列表

场景 3: skill_learned 记忆
  → 正则提取工具序列 → auto_create()
  → 结果: created 列表
```

### 3.3 DreamConsolidator — 记忆消化（`core/utils/dream.py`）

**consolidate_session 5 步管道**：

| 步骤 | 方法 | 功能 |
|------|------|------|
| 1. 提取 | `_extract_fragments` | 从对话中提取知识片段（用户反馈/项目上下文/工具模式） |
| 2. 分类 | — | 按 type 过滤：user/feedback/project/mistake/skill_learned |
| 3. 去重 | `_process_fragment` | MinHash > 0.8 合并，> 0.6 追加，无匹配则新建 |
| 4. 链接 | `_detect_links` | keyword overlap 检测记忆间关联 |
| 5. 衰减 | `_decay_memories` | 60 天未访问 → importance 降低 |

**与旧版 consolidate() 的区别**：

| 特性 | consolidate()（旧版） | consolidate_session()（新版） |
|------|----------------------|------------------------------|
| 触发条件 | 7 重门控检查 | 无门控（会话结束时直接执行） |
| 处理方式 | 4 阶段描述（定向/收集/整合/修剪） | 5 步增量管道（提取/分类/去重/链接/衰减） |
| 数据来源 | 已有记忆文件 | 当前会话对话历史 |
| 并发控制 | PID 锁 | 无需（daemon 线程独占） |
| 返回类型 | `list[str]`（阶段描述） | `ConsolidationReport`（结构化报告） |

### 3.4 server.py — 会话结束钩子

WebSocket 断开时在 `finally` 块中启动后台线程：

```python
# 复制当前历史（线程启动前）
_session_messages = list(agent.history)
_session_id = agent.current_session_id or "unknown"

def _session_end_digest():
    # A. 记忆消化
    mm = MemoryManager(); mm.load_all()
    consolidator = DreamConsolidator()
    report = consolidator.consolidate_session(messages, mm, session_id)

    # B. 重新加载记忆
    mm.load_all()

    # C. 技能进化
    evo_result = SKILL_REGISTRY.evolve_skills_from_memories(mm)

threading.Thread(target=_session_end_digest, daemon=True, name="session-end-digest").start()
```

## 六、设计约束

1. **不修改 agent.py** — 所有增强通过 callback 包装和后置分析实现
2. **不阻塞主流程** — 会话结束消化在 daemon 线程中执行
3. **幂等性** — evolve_skills_from_memories 检查 has_guard/can_ai_modify 防止重复操作
4. **用户至上** — locked=true 的技能 AI 不可修改，用户始终拥有完整权限
5. **增量而非全量** — consolidate_session 只处理当前会话，不重新处理历史数据
