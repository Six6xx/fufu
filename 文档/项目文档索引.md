# 芙芙项目文档

> 本文档面向快速理解代码与面试复盘。架构描述以仓库源码为准；动态运行数据、模型权重和第三方镜像不作为源码结构的一部分。

## 项目是什么

这是一个以 Python 为后端、浏览器页面为前端的个人 AI 助手项目。它将对话推理、工具执行、会话与记忆、语音交互、认知循环和可选 RAG 处理组合在一起；前后端通过 WebSocket 传递流式文本、工具状态和音频。

## Windows 启动

在项目根目录 PowerShell 中运行 `.\run_windows.ps1 --server`。首次启动前安装基础 Web 依赖：`python -m pip install fastapi uvicorn python-multipart openai python-dotenv`，并在项目根目录配置 `.env` 中使用的模型 API。CLI 模式可运行 `.\run_windows.ps1`。语音输入/本地 TTS 还需要额外安装 ASR、音频和 CosyVoice 依赖；本地 TTS 模型目录通过 `TTS_MODEL_PATH` 设置，未配置时仅使用已配置的远程 TTS。

> 若 PowerShell 的执行策略阻止本地脚本，可在当前窗口用 `Set-ExecutionPolicy -Scope Process Bypass` 后重试。当前工作区的 Python 环境缺少 FastAPI、uvicorn 和 OpenAI SDK，尚不能在此环境完成 Web 服务启动。

## 技术构成（以源码导入为准）

- 后端：Python、FastAPI、WebSocket、OpenAI 兼容客户端、asyncio 与线程协作。
- 前端：原生 JavaScript 与 CSS；页面按编号顺序加载脚本，含语音、会话、MCP、技能设置和 Live2D。
- 语音：ASR 引擎、CosyVoice TTS 封装、远程 TTS 客户端与路由器。
- 检索：文本分块、向量存储、混合检索、重排和图聚类等模块。
